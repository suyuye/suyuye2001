## 入门

Framer Motion 是 React 生态中最流行的动画库之一。

### 基本动画

```tsx
<motion.div
  animate={{ x: 100, opacity: 1 }}
  transition={{ duration: 0.5 }}
/>
```

### 手势动画

```tsx
<motion.div
  whileHover={{ scale: 1.05 }}
  whileTap={{ scale: 0.95 }}
/>
```
