## 欢迎

这是使用 **Next.js** 和 **Tailwind CSS** 构建的个人博客。

### 特性

- ✨ **卡片化设计** — 所有内容区块采用圆角卡片
- 🌓 **暗黑模式** — 丝滑的亮色/暗色切换
- 🧊 **毛玻璃导航** — Glassmorphism 风格顶部导航栏
- 📝 **Markdown 支持** — 本地 MDX 文件驱动内容

### 代码示例

```typescript
function greet(name: string): string {
  return `你好，${name}！`;
}

console.log(greet('World'));
```
