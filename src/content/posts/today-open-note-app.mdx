我桌面上一直缺一样东西。

不是更好的壁纸，也不是更花哨的插件。我想要的，是一张能随时写字、又不会打断我手头事情的小纸片。系统自带的便签太素，Notion 太重，云端笔记又要联网、要登录、要等它同步——等我打开它，刚才那点灵感已经凉了。

市面上不是没有好用的桌面便签。只是我总会在某个瞬间被卡住：不能贴边收起、不能自定义配色、不能换字体、待办和正文是两套东西……每一个都算不上致命，但凑在一起，就是「差一点」。

于是我决定自己做一个。

它叫 **今日营业中**——一间开在你桌面上的小小信件管理室。每一张便签，都是一封信。

## ✉️ 为什么叫「今日营业中」

刚好有个笔记本叫这个名字，随便取的，感觉还挺有意思的。

## 🎨 第一眼：它长什么样

便签本体是一张带着纸张质感的卡片，配一抹暖色阴影，安安静静地躺在桌面上，不会抢你的注意力。

![01-便签-常规形态（米黄深）.png](https://cdn.jsdelivr.net/gh/suyuye/blog-images@main/img/01-%E4%BE%BF%E7%AD%BE-%E5%B8%B8%E8%A7%84%E5%BD%A2%E6%80%81%EF%BC%88%E7%B1%B3%E9%BB%84%E6%B7%B1%EF%BC%89.png)

*常规形态：标题栏 + 正文区 + 底部状态栏（字数 · 时间）*

它有 **12 种配色**——米黄、薄荷、雾蓝、豆沙、紫罗兰、高级灰，每个色相又分深浅两档。所有颜色都不是随手挑的：便签上的每一个细节色（阴影、分隔线、复选框、卷角），都能从这张便签自己的底色里推导出来。这是这个软件一直守着的规矩——**长在便签上的颜色，必须来自它自己**。

![09-便签-配色多样.png](https://cdn.jsdelivr.net/gh/suyuye/blog-images@main/img/09-%E4%BE%BF%E7%AD%BE-%E9%85%8D%E8%89%B2%E5%A4%9A%E6%A0%B7.png)

*一套色卡，深浅各异，都带纸张纹理*

## 📐 三种形态：它懂得什么时候该「收起自己」

一张便签不该永远占据同样的空间。所以它有三种模样，各守各的规矩：

**常规**——标题栏、正文、状态栏一应俱全，是一张完整的信纸。

**极简**——收起标题栏，只留正文和纸纹，整张便签变成一块干净利落的桌面磁贴。适合只写几个字、只当个提醒的场景。

![05-便签-极简形态.png](https://cdn.jsdelivr.net/gh/suyuye/blog-images@main/img/05-%E4%BE%BF%E7%AD%BE-%E6%9E%81%E7%AE%80%E5%BD%A2%E6%80%81.png)

*极简形态：去掉一切多余的框，只留内容和纸*

**折叠**——收成一颗圆角胶囊，只露标题和待办计数。像把信折起来塞进信封，还能一眼看见「这里有 2 件事没做完」。

![06-便签-折叠形态（胶囊）.png](https://cdn.jsdelivr.net/gh/suyuye/blog-images@main/img/06-%E4%BE%BF%E7%AD%BE-%E6%8A%98%E5%8F%A0%E5%BD%A2%E6%80%81%EF%BC%88%E8%83%B6%E5%9B%8A%EF%BC%89.png)

*折叠形态：胶囊上的 ☑ 2 表示还有两条待办*

顺手加的一个小东西是**卷角**——便签右下角可以折起一小块，纯粹是让纸更像纸。折角那一块的颜色跟着便签底色走，亮面提亮、折痕压暗，翻起来就像同一张纸的一部分。

![07-便签-卷角.png](https://cdn.jsdelivr.net/gh/suyuye/blog-images@main/img/07-%E4%BE%BF%E7%AD%BE-%E5%8D%B7%E8%A7%92.png)

*右下角翻起的一只小角，不承担任何功能，只为了「像纸」*

## ✅ 待办：把复选框写进正文里

我不喜欢「待办」和「笔记」分成两个 App。所以在正文里直接用最轻量的 Markdown 语法就行：

```
- [ ] 还没做的事
- [x] 已经做完的事
```

它会立刻渲染成自绘的复选框，勾上的那行自动划上删除线。复选框、横线、颜色全都跟着便签底色走——换一张便签，整套待办也跟着换一身衣服。

![08-便签-待办复选框.png](https://cdn.jsdelivr.net/gh/suyuye/blog-images@main/img/08-%E4%BE%BF%E7%AD%BE-%E5%BE%85%E5%8A%9E%E5%A4%8D%E9%80%89%E6%A1%86.png)

*写完即勾，勾完即划*

## 🧲 贴边收纳：让它「滑」到屏幕边上

便签最怕的就是「占地方」。所以拖到屏幕左/右边缘松手，它会自动吸附并收起成一条细边；鼠标靠近就滑出来，移开约半秒又自动缩回去。

拖动的时候，靠近的那一侧会亮起琥珀色竖边并提示「松手贴到左边 / 松手贴到右边」——**看到提示就可以松手，不用去猜距离**。

而且它永远不会完全消失：收起时必定留一条细边，随时能用鼠标找回来。这个功能默认关着，你第一次把它拖到边缘时，软件会自动帮你打开——因为「把便签拖到边缘」这个动作本身，就已经说明你想贴边了。

## 🖼️ 图片也能贴进便签里

写东西的时候，常常需要配一张图。直接 `Ctrl + V` 粘贴，或者从「更多」菜单里选「添加图片…」，图片就会被收进数据库，缩略图显示在标题下方。

重点是：**图片存在数据库里，会跟着备份一起走**。不会出现「备份成功、图片却丢了」这种事。如果你删掉了一封信，它名下的图片也不会变成看不见的垃圾——设置里有一页专门帮你统计和清理。

*设置提醒：单次 / 每日 / 每周 / 工作日 / 每月*

## 🏠 信件管理室：所有信都在这里

`Ctrl + Alt + F` 唤出主界面，就是这间「信件管理室」——左边是分类，中间是信件列表，右边是阅读和编辑区。

![30-列表-完整三栏布局.png](https://cdn.jsdelivr.net/gh/suyuye/blog-images@main/img/30-%E5%88%97%E8%A1%A8-%E5%AE%8C%E6%95%B4%E4%B8%89%E6%A0%8F%E5%B8%83%E5%B1%80.png)

*三栏布局：分类 / 列表 / 编辑区*

分类有七个：**全部、置顶、活跃、待提醒、标签、归档、回收站**。每个分类右边都挂着实时的数量徽标，一眼看清今天有多少信件在等着处理。

![20-列表-全部.png](https://cdn.jsdelivr.net/gh/suyuye/blog-images@main/img/20-%E5%88%97%E8%A1%A8-%E5%85%A8%E9%83%A8.png)

*每一封信带着自己的颜色标记、摘要和时间*

需要找什么，直接搜。关键词会高亮出来，列表实时收敛。

![28-列表-搜索.png](https://cdn.jsdelivr.net/gh/suyuye/blog-images@main/img/28-%E5%88%97%E8%A1%A8-%E6%90%9C%E7%B4%A2.png)

*搜索「信」，结果立刻收敛到两条*

选中一封信，右边的编辑区就会展开——标题、正文、标签、附件、创建与修改时间、字数统计，全在一屏里。还支持**批量操作**：选中多封信，一次置顶、归档、删除、改色或移动标签。

![27-列表-选中信件（编辑区）.png](https://cdn.jsdelivr.net/gh/suyuye/blog-images@main/img/27-%E5%88%97%E8%A1%A8-%E9%80%89%E4%B8%AD%E4%BF%A1%E4%BB%B6%EF%BC%88%E7%BC%96%E8%BE%91%E5%8C%BA%EF%BC%89.png)

*选中信件后，右侧编辑区完整呈现*

## ⚙️ 设置：把能想到的都交给你

设置窗口有五个页面，我把能调的东西都放了出来。

**通用**——开机自启、启动延迟、关闭时最小化到托盘、新便签位置、置顶不抢焦点、自动保存间隔、提醒声音、默认稍后提醒时长。

![40-设置-通用.png](https://cdn.jsdelivr.net/gh/suyuye/blog-images@main/img/40-%E8%AE%BE%E7%BD%AE-%E9%80%9A%E7%94%A8.png)

*通用设置：启动、窗口行为、编辑、提醒*

**外观**——主题（跟随系统 / 浅色 / 深色）、默认便签颜色、默认不透明度、默认字号、便签字体（支持霞鹜文楷等手写字体）。改的时候右边有实时预览，所见即所得。

![42-设置-外观.png](https://cdn.jsdelivr.net/gh/suyuye/blog-images@main/img/42-%E8%AE%BE%E7%BD%AE-%E5%A4%96%E8%A7%82.png)

*外观设置：主题卡片、色板、透明度与字号滑杆，右侧实时预览*

**快捷键**——三个全局快捷键都能改：新建便签（`Ctrl+Alt+N`）、搜索便签（`Ctrl+Alt+F`）、显示/隐藏全部便签（`Ctrl+Alt+H`）。点「修改」，按下新组合键即可，按 `Esc` 取消。

![44-设置-快捷键.png](https://cdn.jsdelivr.net/gh/suyuye/blog-images@main/img/44-%E8%AE%BE%E7%BD%AE-%E5%BF%AB%E6%8D%B7%E9%94%AE.png)

*三个全局快捷键，想换就换*

**数据**——自动备份（可设间隔）、立即备份、打开备份文件夹、备份管理列表，以及 JSON / Markdown / 文本三种格式的导入。备份用的是 SQLite 的 `VACUUM INTO` 快照，干净、安全、不锁库。

![46-设置-数据（下半）.png](https://cdn.jsdelivr.net/gh/suyuye/blog-images@main/img/46-%E8%AE%BE%E7%BD%AE-%E6%95%B0%E6%8D%AE%EF%BC%88%E4%B8%8B%E5%8D%8A%EF%BC%89.png)

*数据设置：备份、备份管理、导入导出*

还有一页**图片附件管理**，告诉你库里一共收了多少张图、占了多少地方、有没有哪几张已经失去了主人（比如它所属的信件被永久删除了）。一键就能清理干净——而回收站里的信，它名下的图片都还有主，绝不会被误伤。

## 🌙 关于主题、字体与那些「小事」

软件支持**浅色 / 深色 / 跟随系统**三种主题，切换即时生效。便签颜色不受主题影响——因为便签是「纸」，纸的颜色不该被房间的灯左右。

字体方面预置了霞鹜文楷等手写字体，圆润的笔触配纸张质感，写起来更舒服。

还有一堆不会上截图、但每天都在替你干活的小事：系统托盘常驻、最小化不占任务栏、输入即保存（停了半个多秒就自动落库）、锁定防误触、双击标题进编辑、右键内容区随时唤出完整菜单。

## 🔧 关于它的「手艺」

说点技术上的：这是一个 **C# / WPF / .NET 10** 写的原生 Windows 应用，数据用 **SQLite** 存在本地（`%APPDATA%\今日营业中\`），单文件发布、自包含运行时——**解压即用，不需要装 .NET，不需要管理员权限，不需要联网**。

它完全免费、开源，遵循 MIT 协议。

写到 v1.5.4 的今天，代码库里有 **354 个单元测试**在守着它。这个版本的更新日志只讲了一件事——修好「选中文字时高亮块错位」的毛病。那是三轮迭代才彻底逮住的虫子，藏在两层缓存的缝隙里：程序把每行文字的位置记在册子上，翻册子时只看这行有多少字、不问写的是什么字，也不管这行在页面上站的位置变没变。于是用了久了，旧账越积越多，高亮就飘了。

我把这段经历写进了更新日志，用的是书信的口气。因为我相信：**一个软件的品格，藏在它怎么对待自己的 bug 里。**
