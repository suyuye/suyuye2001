## 主要变化

Tailwind CSS v4 是一次重大更新。

### CSS-first 配置

不再需要 `tailwind.config.js`，直接在 CSS 中使用 `@theme` 指令：

```css
@theme {
  --color-primary: #425aef;
}
```

### 新的变体系统

```css
@custom-variant dark (&:where(.dark, .dark *));
```

更灵活、更强大的自定义变体系统。
